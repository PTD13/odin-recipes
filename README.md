# odin-recipes
A simple recipe website built as part of [The Odin Project](https://www.theodinproject.com/) Foundations course.
This is the first project that is created as part of the Odin curriculum.

The website will contain some simple recipe pages, each with a description, image, ingredients and steps. The index page will list all of the available recipes in it. Each page will contain a link back to the home page.

By completing this project I will have demonstrated my ability to:
- Create and structure web pages using HTML
- Organize a website using files and directories
- Utilize links between multiple web pages
- Work with basic tags like paragraph, lists, images and anchor
- Use git and GitHub to track and publish my work

I have obtained the recipes, the ingredients, steps and images from [allrecipes.com](https://www.allrecipes.com/). Descriptions were written on my own.
